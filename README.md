# Student Management System

## Description

This project is a simple Student Management System developed using Python.

## Features

- Add student
- Display student details
- Search student
- Update student information
- Delete student

## Technologies Used

- Python
- SQLite

## Installation

Clone the repository:

git clone <repository-url>

## How to Run

Run:

python main.py
